# Support

## Hosted service

If you use the hosted version of one of these products (for example Brainy, LearnStack, Needly or MoneyBrain), use the support or contact options on the product's website for account, billing or subscription questions. Please don't open GitHub issues for those.

## Open source / self-hosted

- **Bugs:** open an issue with the bug report template in the relevant repository.
- **Feature ideas:** open an issue with the feature request template.
- **Questions and help:** if the repository has GitHub Discussions enabled, ask there. Otherwise open an issue and describe what you have tried.
- **Security vulnerabilities:** never in public. Follow the [Security Policy](SECURITY.md).

Self-hosted support is community-based and best-effort. There is no guaranteed response time.
